INSIDE THE IMAGE

Meet your Dockerfile.

Each instruction adds a layer or sets a default that shapes how your app is built and launched.

01BASE

FROM

Choose the starting image. This demo builds on a small Python image.

FROM python:3.12-slim
02FILES

ADD + COPY

Put app files into the image. ADD can unpack archives; COPY is the go-to for regular files.

ADD styles.css ./
COPY index.html app.js server.py ./
03SETUP

WORKDIR + RUN

Set the working folder, then prepare the image with a dedicated app user.

WORKDIR /app
RUN useradd ... appuser
04CONFIG

ENV + USER

Set the default server port and run the app without root privileges.

ENV PORT=8099
USER appuser
05NETWORK

EXPOSE

Document the port the app listens on. Publish it with docker run -p.

EXPOSE 8099
06START

ENTRYPOINT + CMD

ENTRYPOINT starts the server; CMD provides its default host argument.

ENTRYPOINT ["python", "server.py"]
CMD ["--host", "0.0.0.0"]

YOUR TURN

Build it. Run it.

Run both commands from the folder containing the Dockerfile.
